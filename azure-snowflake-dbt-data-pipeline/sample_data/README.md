# Sample Data

This directory documents the expected source-file structure.

Example files:

```text
customers_2026-10-01.csv
products_2026-10-01.csv
orders_2026-10-01.csv
order_items_2026-10-01.csv
```

The project uses these files conceptually as daily source data arriving in the cloud landing zone.

No credentials or sensitive production data should be committed to this repository.
